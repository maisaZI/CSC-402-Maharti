# Integrated Android Project

The team's single Android Studio project will be placed here after it has been created and verified. This is currently a placeholder, **not a runnable application**.

Expected Android Studio structure once uploaded:

```text
AndroidProject/
├── settings.gradle.kts
├── build.gradle.kts
└── app/
    ├── build.gradle.kts
    └── src/main/java/<team-package>/
        ├── ui/screens/
        ├── ui/theme/
        └── navigation/
```

All future functionality should be developed in this same integrated project. Do not upload multiple competing app copies.
