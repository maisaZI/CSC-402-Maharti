# Milestone 3 — Stage 2

This workspace preserves individual screen submissions while keeping one integrated Android Studio application.

- `individual-work/`: each member commits her own Kotlin files under her named folder. These copies document contributions and are **not** the runnable app.
- `report/`: the final team PDF, `Team##_M3B_Screens.pdf`, when approved.
- `../../AndroidProject/`: the one integrated Android Studio project. Do not create a separate Android project for each student.

**Workflow:** individual commit → integration in AndroidProject → verify all screens/routes and build → commit integrated version → prepare PDF → create required milestone tag.

Do not upload unfinished experimental code as the final submission. Preserve original author attribution.
