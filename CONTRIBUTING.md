# How each student uploads her work

1. Open the repository on GitHub and select the branch `milestone-2` as the base.
2. Create your own branch: `stage2/samar`, `stage2/lyan`, `stage2/lena`, `stage2/monera`, `stage2/reyouf`, `stage2/maisa`, or `stage2/haya`.
3. Upload files to your personal `team/<name>/stage-2/` folder and any official deliverable path in `docs/`.
4. Commit your files and open a Pull Request **into `milestone-2`**. Link your assigned Issue.
5. Maisa reviews the PR and approves if correct. A different member must review Maisa's own PR.
6. Merge the reviewed PR, close its Issue, and record the PR number in GitHub Evidence.

Do not upload another member's work under your own account. Do not invent past contributions or approvals.
